# Legends Reawakened

A scroll-driven 3D storytelling website exploring five myths and folklore tales (Icarus, Ravana's Ten Heads, Yakshi, Phoenix, Kappa).

## Tech Stack
- HTML, CSS, JavaScript
- Three.js
- GSAP ScrollTrigger

## About
Built for CODEFLARE 2.0 (IEEE Student Branch, Saintgits College) — theme: Mythology and Folklore.

## How to Run
No build step is required! Simply open `index.html` in your web browser.
